# מטלגרם לדרייב

אתר שמעתיק את כל הקבצים מערוץ טלגרם (סרטונים, שמע, קבצים ותמונות) לתיקייה בגוגל דרייב, עם פסי התקדמות.

- רץ כולו בדפדפן, בלי שרת ובלי עלות.
- מתחבר לטלגרם עם החשבון שלך (GramJS) ומעלה לדרייב בחלקים של 8MB, כך שגם קבצים של כמה ג'יגה עוברים בלי לתפוס זיכרון.
- זוכר מה כבר הועתק (לפי מזהה ההודעה ששמור בקובץ בדרייב), אז אפשר לעצור ולהמשיך.
- מצבים: כל הארכיון, ארכיון + חדשים, או רק חדשים (כל עוד הדף פתוח).

המפתחות (Telegram api_id/api_hash, Google Client ID/API key) מוזנים במסך ההגדרות ונשמרים רק בדפדפן.
